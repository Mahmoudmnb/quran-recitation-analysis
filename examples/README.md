# Public format examples

These files are **format demonstrations, not real model predictions**. They contain generic placeholder labels rather than fabricated Quranic phonemes. They do not define a public inference API.

- [sample-phoneme-sequence.json](sample-phoneme-sequence.json): an illustrative recognized sequence. Confidence is `null` because no measured or calibrated confidence is supplied.
- [sample-analysis.json](sample-analysis.json): a synthetic timing record showing start, end, and duration fields. Its Tajweed status is explicitly `illustrative_only`.

All numeric timestamps are illustrative. No example comes from private audio, the training dataset, or an actual inference run. No correctness judgment or Tajweed performance metric is encoded.
